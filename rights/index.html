隐私权利

适用应用：衡绘 Hengraph 0.2.2 页面更新：2026-10-21

你的数据在你手上。衡绘没有账号、没有云端、没有后台。因此你的隐私权利不通过“提交工单”实现， 而是直接在应用内完成：查看项目、逐个删除、卸载清除。本页说明每一步的确切路径与影响范围。

01查看本地保存的项目

路径：首页“最近项目”区域 → “查看全部 ›”；或底部导航栏“项目”标签。

  • 列表按保存时间展示每个项目的摘要信息（项目名称、保存时间、数据规模）。
  • 项目卡片右侧的“⋯”菜单提供三项操作：打开、重命名、删除。
  • “我的”标签下另有一个“我的数据”区块，显示本应用保存的项目数量与占用空间合计（仅统计本应用保存的项目文件）。

衡绘不会在应用内展示或管理你设备上其他位置的文件。

02删除单个项目

操作步骤：

  1. 进入底部“项目”标签；
  2. 在目标项目右侧点击“⋯”；
  3. 选择“删除”；
  4. 在确认弹窗中点击“确认删除”。

确认前会看到提示：“删除后该项目的源数据将被移除，且不可恢复。”若选择“取消”，不会发生任何改动。

该操作覆盖什么

  • 该项目目录下的全部版本快照（v-<时间戳>），其中包含 manifest.json 与 source.csv；
  • 该项目的 current 指针与项目目录本身；
  • 删除后该项目不再出现在项目列表中，也无法再打开或导出。

删除是不可恢复的：衡绘不把内容留在回收站、缓存或任何服务器副本中。若删除失败，应用会显示失败原因， 而不是静默忽略。

03删除全部数据

有两种方式，效果相同：

  • 卸载应用：在系统桌面长按图标卸载，或在系统设置的应用管理中卸载；
  • 清除应用数据：系统设置 → 应用和服务 → 衡绘 → 存储 → 清除数据。

这两种操作会移除应用沙箱内的全部项目、源 CSV 副本与本地偏好设置。

04什么不会被上述操作删除

请特别注意以下三类内容，它们不在应用的控制范围内：

内容为什么不会被删除如何处理
原始 CSV 文件 它位于你导入前存放的位置（如“文件管理”中的下载或文档目录），应用只是读取，未曾移动或删除它 在文件管理中自行删除
已导出的 PNG / SVG / CSV / JSON 导出时写在你选择的目录，可能已位于公共存储或已分享给其他应用 在对应目录或应用中自行删除；已分享出去的副本需向接收方请求删除
系统备份中的副本 若你启用了 HarmonyOS 系统备份或换机迁移，沙箱数据可能随系统备份被处理 在系统设置的备份管理中删除对应备份

05更正与导出

  • 更正：项目名称可通过“⋯ → 重命名”修改。数据内容本身以你导入的 CSV 为准，衡绘不会改写你的原始数值；如需修正数据，请修改源文件后重新导入。
  • 导出：任何时候你都可以把当前项目导出为 PNG、SVG、CSV 与清单文件，将数据带到其他工具中。

06未实现的操作与说明

为避免误导，以下操作在衡绘中不存在，因为它们所针对的对象也不存在：

  • 账号注销：应用没有账号体系，无需也不能注册登录，因此没有账号注销入口；
  • 云端数据删除申请：应用不向任何服务器上传数据，开发者侧没有你的数据副本可供删除；
  • 隐私开关 / 遥测开关：不存在可关闭的数据采集项，因为本身没有采集、统计或崩溃上报组件；
  • 隐私设置页：应用内“我的 → 隐私与数据管理”仅为静态说明文字，不含任何数据提交开关。

如果你认为本应存在某项操作而实际没有，请通过下方渠道告知开发者，我们会在后续版本中评估。
